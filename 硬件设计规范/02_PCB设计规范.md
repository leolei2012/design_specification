## 1. 目的、规则等级与适用边界

使PCB的结构、电气、制造、装配、测试及交付要求可执行、可检查、可追溯。本文件是结合TI、ADI、ST、NXP公开资料形成的团队规范建议稿，不代表这些企业的内部标准，也不构成产品认证结论。具体资料及采用范围见第16章。

- **必须**：发布前满足；偏离时记录原因、风险、验证证据与批准人。
- **应**：默认执行，不采用时记录理由。
- **建议**：根据项目成本、空间与维护需求选择。

DDR、射频天线、超高速串行链路、高压/市电、大功率，以及汽车、医疗等产品需另编专项规则。本文件只提供设计管理入口，不能替代接口规范、器件要求或产品适用标准。

参考设计必须核对芯片型号、封装、叠层、材料和工作条件。资料冲突时核实版本、勘误及适用范围并提交评审，不自行采用较宽松要求。未确定的参数标记“待确认”，不得带入已批准的生产发布包。

## 2. 设计输入与流程

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| IN-01 | 必须 | 输入包括已评审原理图、BOM、结构图、接口定义、电源预算、PCB约束及选配状态；记录对应版本。 |
| IN-02 | 必须 | 明确板框、厚度、公差、安装孔、连接器位置、器件限高、插拔空间、禁布区、散热接触面及装配方向。 |
| IN-03 | 必须 | 布局前与板厂和装配方确认工艺能力、材料、叠层、铜厚、孔工艺、阻焊、表面处理和拼板要求。 |
| IN-04 | 必须 | 核对封装焊盘号、尺寸、引脚1、极性及器件实体外形；3D模型仅用于辅助，不能代替封装图核对。 |
| IN-05 | 必须 | 建立关键网络清单及规则优先级，检查规则作用范围和覆盖关系，避免默认规则覆盖专项约束。 |

建议流程：输入确认 → 工艺与叠层确认 → 结构件定位 → 关键电路布局 → 布局评审 → 关键网络布线 → 普通布线及铺铜 → DRC与专项复核 → 制造文件检查 → 发布。

阶段门槛：布局评审必须确认关键回路和布线通道可实现；生产发布必须完成第14章条件。原理图修改通过受控同步导入，禁止在PCB中私改电气连接而不回写原理图。

## 4. 叠层、参考平面与回流

高速部分参考[P1]；混合信号部分参考[P3]。下表是据此形成的项目检查要求。

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| STK-01 | 必须 | 布线前确定叠层及每个关键布线层的参考平面；阻抗计算使用板厂确认的实际几何与材料参数。 |
| STK-02 | 应 | 关键高速、时钟网络邻近连续参考平面；层数由布线、回流、散热和制造需求决定，不能只按引脚数量决定。 |
| STK-03 | 必须 | 关键网络不得未经分析跨参考平面分割、开槽或密集反焊盘形成的断口；必要变更须评估回流与阻抗。 |
| STK-04 | 必须 | 关键网络换层时核查参考关系及回流转换路径；同地参考转换可设置邻近接地过孔，不同参考网络按专项方案处理。 |
| STK-05 | 必须 | 电源和地的铜皮连接不能只看网络名；检查实际连通、回流通道及细颈，避免孤岛和意外串接。 |
| STK-06 | 必须 | 模拟与数字区域通过布局和回流控制隔离干扰；不因AGND/DGND名称就机械分割地，具体连接遵循所选器件和系统方案。 |

四层板可从“信号/连续地/电源及必要信号/信号”的方案开始评估，但必须逐层验证关键网络的参考关系。此示例不是批准叠层，底层信号也不能默认拥有连续地参考。

## 5. 器件布局

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| PLC-01 | 必须 | 先固定结构约束件，再安排电源、时钟、敏感模拟及关键接口；避免布线完成后才发现插拔或安装干涉。 |
| PLC-02 | 应 | 按信号流和功能分区，减少跨区域连接；干扰源与敏感接收电路保持有依据的隔离。 |
| PLC-03 | 必须 | 关键器件按回路关系摆放，并给出对应截图和依据；“离得近”不能代替短电流回路。 |
| PLC-04 | 必须 | 检查上下两面器件、螺钉、垫片、线束及外壳的最坏公差干涉；金属固定件的铜禁布区单独确认。 |
| PLC-05 | 应 | 同类器件方向尽量一致，极性和引脚1易检查；满足电气性能与焊接工艺优先于图面整齐。 |
| PLC-06 | 必须 | 预留连接器锁扣、工具、探针、返修及散热器安装空间；DNP器件仍需考虑邻近装配影响。 |

布局评审至少提交：板框和关键尺寸、功能分区、主电流路径、关键回路、敏感节点、热源、接口保护位置和3D装配图。

## 6. 通用布线、过孔与铺铜

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| RTE-01 | 必须 | 先布置有约束的网络及其回流，再完成普通信号；不得用自动布线结果替代关键网络检查。 |
| RTE-02 | 应 | 常规拐角采用45°或圆弧，减少尖角、无用途回绕和碎线；高速性能需依据实际阻抗与不连续性判断。 |
| RTE-03 | 必须 | 原理图中“减少交叉”的规则不直接用于PCB：异层交叉可接受，但必须满足参考平面、串扰和间距要求。 |
| RTE-04 | 必须 | 过孔尺寸和工艺在板厂能力内；焊盘过孔是否填孔、盖孔、塞孔或开窗，必须与板厂及装配方确认。 |
| RTE-05 | 必须 | 线宽改变、焊盘出线、过孔和铺铜细颈处校核实际载流、压降及阻抗；不能只检查主干宽度。 |
| RTE-06 | 必须 | 铺铜在最终修改后全部重新计算；检查孤岛、细长铜片、窄通道及误连接，不保留无定义的悬浮铜。 |
| RTE-07 | 必须 | 热焊盘连接方式同时满足焊接和电气热要求；直连或热焊盘不可按器件类别一刀切。 |
| RTE-08 | 应 | 地过孔和边缘缝合结合回流、屏蔽及工艺需要设置；不统一规定全板固定间距，也不得跨越隔离区。 |

## 7. 电源、去耦与大电流

开关电源布局参考[P2]。以下规则要求结合实际拓扑，不将Buck示例直接套用到Boost、反激或其他拓扑。

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| PWR-01 | 必须 | 标出正常导通及换流路径，识别高di/dt回路；优先紧凑连接其关键电容和开关器件。 |
| PWR-02 | 必须 | SW等高dv/dt节点在满足电流和散热条件下限制面积，远离反馈、采样、晶体和接口；邻层耦合也需检查。 |
| PWR-03 | 必须 | 反馈与补偿器件靠近对应引脚，采样点按芯片要求选取；采样回流避免与功率回流共用产生误差的路径。 |
| PWR-04 | 必须 | 去耦检查“电源脚—电容—地回路”的完整路径及过孔连接，不仅量器件间直线距离；按器件要求确定优先级。 |
| PWR-05 | 必须 | 大电流路径按成品铜厚、层别、环境、允许温升及压降计算，检查连接器、焊盘、过孔和细颈的全路径能力。 |
| PWR-06 | 必须 | 电流采样需要Kelvin连接时，从规定端点独立引出采样线，避免功率铜压降进入测量；核对器件端子定义。 |
| PWR-07 | 必须 | 多层并流必须检查过孔电流分配及连接位置；不能以过孔数量简单推定载流能力。 |
| PWR-08 | 应 | 预留电源纹波、启动及故障测量位置，提供邻近地参考；大电流测试工装也需符合连接能力。 |

## 8. 高速、差分、时钟与等长

本章参考TI高速指南[P1]，只提取检查原则。USB、PCIe、以太网、DDR等分别建立专项约束，具体数值以相应版本及芯片要求为准。

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| SIG-01 | 必须 | 根据上升/下降时间、传播时延和链路要求识别高速网络，不能只按时钟频率判断。 |
| SIG-02 | 必须 | 阻抗线按批准叠层配置线宽、间距、参考层及容差；板厂调整几何或材料后重新评估。 |
| SIG-03 | 应 | 差分对维持受控几何及对称的参考环境；焊盘逃线、器件和换层造成的不对称应缩短并检查。 |
| SIG-04 | 必须 | 等长以时序预算为依据，区分对内偏差、组间偏差和最大总延迟；需要时包含封装、过孔及连接器影响。 |
| SIG-05 | 必须 | 禁止为等长无依据地大量蛇形；补偿后检查自耦合、串扰和局部参考，必要时按时延而非几何长度验证。 |
| SIG-06 | 必须 | 核查过孔、残桩、连接器及测试支路等不连续点；是否背钻或使用盲埋孔由链路分析及工艺决定。 |
| SIG-07 | 必须 | 端接、交流耦合及保护器件位置按对应接口和芯片要求，不能统一要求全部放在源端或接收端。 |
| SIG-08 | 必须 | 高风险链路明确损耗、串扰和时序验证方法；需要仿真或测量的项目记录模型、边界条件与通过标准。 |

晶体与时钟布局：按所选振荡电路保持紧凑，减少与噪声网络耦合，晶体负载回路按器件指南实现；是否禁布、护地或屏蔽按具体方案确认。[P4] 禁止将“晶体下方全部挖空”写成所有产品通用规则。

## 9. 模拟、基准与敏感测量

接地策略参考[P3]，采用以下项目检查要求：

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| ANA-01 | 必须 | 模拟输入、基准和高阻节点远离开关节点、数字时钟及大电流回路，同时检查相邻层耦合。 |
| ANA-02 | 必须 | ADC驱动、滤波和参考去耦按器件要求布局，复核PCB寄生对建立时间、噪声和稳定性的影响。 |
| ANA-03 | 必须 | 差分测量保持路径和环境平衡；敏感回流不经过驱动、功率或接口放电的公共阻抗。 |
| ANA-04 | 必须 | 高阻节点检查表面漏电、阻焊、污染及清洗要求；保护环等措施须确认驱动电位及稳定性。 |
| ANA-05 | 应 | 精密通道避开热源和明显温度梯度；有微弱信号要求时评估热电势及器件热耦合。 |

不根据AGND/DGND名字直接决定开槽或磁珠连接。记录实际器件建议、系统回流方案及验证结果；多转换器系统尤其需要单独检查。

## 10. EMC、接口防护与隔离

布局中的回路与耦合控制参考ST指南[P4]；防护目标及验证等级由产品项目确定。

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| EMC-01 | 必须 | ESD/浪涌保护靠近预定入口布置，检查入口到保护器件、再到泄放参考的完整路径，避免干扰先经过内部电路。 |
| EMC-02 | 必须 | 电缆屏蔽、机壳地、保护地和信号地连接按系统方案实现，明确放电电流去向及机械连接可靠性。 |
| EMC-03 | 必须 | 滤波前后区域保持隔离，检查跨层绕接和耦合是否绕过滤波；保护器件布局不能只按距离判定。 |
| EMC-04 | 必须 | 隔离边界检查全部铜层、焊盘、过孔、器件、开槽和金属固定件；爬电路径与空间距离分别核查。 |
| EMC-05 | 必须 | 保护地及安全相关连接不得未经依据通过可断开的细颈、热焊盘或选配器件；接法按产品要求独立评审。 |
| EMC-06 | 应 | 为屏蔽、共模滤波及吸收网络保留有依据的调试方案；DNP状态不能造成不受控支路或破坏高速性能。 |

## 11. 散热与机械可靠性

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| THM-01 | 必须 | 依据最坏损耗、环境、气流、外壳及相邻热源评估温度，定义结温/壳温测量或估算方法。 |
| THM-02 | 必须 | 不将数据手册特定测试板的热阻直接当作实际整板结果；关键器件需要项目计算、仿真或实测依据。 |
| THM-03 | 必须 | 裸露焊盘连接到器件规定网络，热过孔、铜区及焊接方案协调设计；不能因其散热功能默认接地。 |
| THM-04 | 必须 | 散热器、导热垫、压紧件检查公差、电气绝缘和接触压力，并考虑返修及安装顺序。 |
| THM-05 | 应 | 易受板弯应力影响的器件避开分板边、螺钉和连接器受力区；具体距离与工艺方确认。 |

## 12. 封装、制造、装配与测试

QFN/SON相关封装与装配检查参考[P5]，BGA逃线和工艺协同参考[P6]。以下同时包含团队交付约定。

| 编号 | 等级 | 规则及检查依据 |
|---|---|---|
| MFG-01 | 必须 | 焊盘、阻焊和钢网开窗依据精确封装图及装配条件确认；禁止相似封装直接复用而不核查。 |
| MFG-02 | 必须 | QFN/SON裸露焊盘的锡膏分割、过孔及吸锡影响与装配方确认，不能统一整块开窗或套用固定覆盖比例。 |
| MFG-03 | 必须 | BGA核对球位、焊盘、扇出、阻焊及孔工艺；文献中的示例线宽、孔径及层数不可直接作为其他BGA的规则。 |
| MFG-04 | 必须 | 区分PTH与NPTH、成品孔与钻孔；槽孔、压接孔及沉孔在制造图单独标注。 |
| MFG-05 | 必须 | 丝印不压焊盘、开窗和关键标记；板名、硬件版本、引脚1及极性清楚，底层丝印检查实际装配视角。 |
| MFG-06 | 必须 | 贴片原点、单位、坐标、旋转角及顶底层定义与装配方一致；用已知极性器件复核坐标文件方向。 |
| MFG-07 | 应 | 根据装配流程设置全局/局部基准点、工艺边和拼板连接；V割、邮票孔及分板应力范围确认后再发布。 |

## 14. 发布条件与交付物

### 14.1 发布条件

1. 原理图与PCB版本一致，执行工程同步比较，所有非预期差异关闭。
2. 全部铺铜重算后执行DRC；短路、未布线、间距和工艺问题关闭。剩余规则例外逐项审核，禁止批量屏蔽取得“通过”。
3. 项目参数表已填写，关键约束可追溯，必要的仿真、计算及评审完成。
4. 结构、板厂及装配要求已核对；阻断发布的问题关闭，遗留项有批准记录。
5. 实际导出的Gerber/ODB++等文件用独立查看器检查：层序、板框、钻孔、阻焊、钢网、丝印及内层铜。不能只检查EDA源文件。
6. 确认输出包与源版本、BOM和装配变体一致，文件命名和版本清单明确；输出后再修改设计则必须重新生成并复核受影响文件。

### 14.2 交付清单

- PCB与原理图源文件、依赖库版本或快照。
- 制造数据：按板厂约定提供Gerber、ODB++或IPC-2581等格式；若多格式并存，指定受控制造主数据，避免不一致。
- 钻孔/槽孔数据及PTH、NPTH说明，板框、叠层、材料、成品铜厚、阻抗及特殊工艺图。
- BOM、DNP/装配变体、坐标文件、顶底面装配图和特殊焊接说明。
- 钢网数据及特殊开窗说明；由装配方最终调整时，保留已批准版本。
- PCB关键约束、计算/仿真、结构核对和评审记录。
- DRC报告、制造输出检查结果、版本变更与发布清单。
